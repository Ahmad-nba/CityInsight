# 🌆 City Insight

**Explore the pulse of any city — weather, news, and visuals in one clean dashboard.**  
Now optimized for performance, SEO, and production-readiness.

---

## 📌 Overview

**City Insight** is a fast, responsive, and SEO-optimized city dashboard built with **Next.js 15 (App Router)**. It allows users to quickly explore:

- 🌦️ Real-time weather metrics
- 📰 Latest news updates
- 🖼️ High-quality city-specific images

This project showcases strong full-stack skills and professional-grade implementation of **performance optimization**, **server-side rendering**, and **modular frontend architecture**. Version 1.1 marks a mature stage for recruiters and collaborators to evaluate.

> ✅ **V1.1: SEO-ready, fully responsive, and visually refined**  
> 🚧 Still under active development: Version 2 will bring even more polish and functionality.

## 🧱 Tech Stack

| Area               | Technology / Tool                                                |
| ------------------ | ---------------------------------------------------------------- |
| Framework          | [Next.js 15 (App Router)](https://nextjs.org/)                   |
| Styling            | [Tailwind CSS](https://tailwindcss.com/)                         |
| State Management   | [Zustand](https://zustand-demo.pmnd.rs/)                         |
| SEO                | Dynamic Sitemap, robots.txt, `<meta>` tags                       |
| Image Optimization | [Next/Image](https://nextjs.org/docs/api-reference/next/image)   |
| Icons              | [React Icons](https://react-icons.github.io/react-icons/)        |
| Carousel           | Custom-built with `react-slick`                                  |
| APIs               | OpenWeather API • NewsData API • Unsplash API • GeoDB Cities API |

---

## ✨ Core Features

- 🔍 Search & discover any global city
- 🌤️ Get real-time weather stats (temperature, humidity, wind)
- 📰 Read up-to-date city-specific news
- 🖼️ Browse curated imagery per location
- 💾 Save favorite cities locally (client-side state)
- 📱 Fully responsive design
- 🚀 Blazing fast — server-rendered pages and prefetching
- 🌐 **SEO Boosters**:
  - Dynamic `sitemap.xml`
  - Custom `robots.txt`
  - Meta title and description per page
  - Optimized image rendering with `next/image`
